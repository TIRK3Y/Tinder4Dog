# Tinder4Dog

A static, single-page landing page for a fictional dog-matching app called "Tinder4Dog". It is a front-end practice project built with HTML, CSS, and Bootstrap 5.

## Overview

The page is laid out as a typical product landing page:

- **Title section**: headline ("Meet new and interesting dogs nearby."), a phone mockup image, and App Store / Google Play style download buttons.
- **Features**: three feature blocks with Bootstrap Icons SVGs.
- **Testimonial**: a quote with a profile photo, followed by a row of press logos.
- **Pricing**: three plan cards (Chihuahua, Labrador, Bull) priced in rupees.
- **Footer**: copyright line and placeholder navigation links.

The title and footer sections use an animated CSS gradient background. Buttons and links are visual only; there is no custom JavaScript beyond the Bootstrap bundle.

## Contents

| Path | Description |
| --- | --- |
| `index.html` | The landing page markup, using Bootstrap 5.3.3 from the jsDelivr CDN. |
| `style.css` | Custom styles: animated gradient background, icon squares, and round profile image. |
| `images/` | Phone mockup (`iphone.png`), testimonial photo (`benzi.jpg`), and press logos (`techcrunch.png`, `mashable.png`, `tnw.png`, `bizinsider.png`). |

## Tech stack

- HTML5
- CSS3 (keyframe animation)
- Bootstrap 5.3.3 (CSS and JS bundle via CDN)

## Getting started

No build step is required. Clone the repository and open `index.html` in a web browser. An internet connection is needed to load Bootstrap from the CDN.

```bash
git clone https://github.com/TIRK3Y/Tinder4Dog.git
cd Tinder4Dog
# open index.html in a browser
```
